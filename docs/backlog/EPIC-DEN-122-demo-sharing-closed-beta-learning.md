# DEN-122 · Demos compartibles y aprendizaje para beta cerrada

## Resultado
Un administrador comparte un enlace PyME o Startup. El invitado inicia sesión y Denarius crea una copia personal, editable y reiniciable del escenario. Existe un centro de aprendizaje permanente orientado a decisiones.

## Criterios de aceptación
- El enlace nunca contiene tenant, usuario, monto ni secreto.
- La demo exige autenticación y se provisiona con `auth.uid()`.
- El invitado no puede leer ni modificar la copia del administrador.
- Hay recorridos separados para PyME y Startup.
- El tutorial es omitible, repetible y accesible por teclado.

## No aceptamos
- Compartir credenciales o sesiones administrativas.
- Exponer una demo viva a varias identidades.
- Un tour obligatorio o sin resultado de negocio.
- Telemetría con montos, nombres o texto financiero.
